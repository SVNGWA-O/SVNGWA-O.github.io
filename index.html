eNotaryRW

Online notarization in Rwanda. The leading eNotary platform.

I founded and engineered eNotaryRW from the first line of code to production. The platform matches clients with available private notaries and cuts notarization turnaround from days to seconds. A real-time matching engine built on a Java backend pairs every client with a qualified notary by availability and document type, and a secure React document workflow preserves tamper-evident audit trails for full legal integrity. It was built quietly and engineered carefully, and it is already serving real users.
